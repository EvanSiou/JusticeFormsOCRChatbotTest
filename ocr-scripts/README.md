# OCR Scripts

Standalone Python scripts and environment configuration for the OCR testing project.

## Scripts

| File | Description |
|------|-------------|
| `create_ai_technique_justification.py` | Generate AI technique justification document |
| `create_evaluation_validation_memo.py` | Generate evaluation and validation memo |
| `create_one_pager.py` | Generate project one-pager summary |
| `verify_environment.py` | Verify Python environment and dependencies |
| `setup_workbench.sh` | Shell script for Vertex AI Workbench setup |

## Requirements

| File | Description |
|------|-------------|
| `requirements.txt` | Local development dependencies |
| `requirements-cloud.txt` | Cloud/Vertex AI Workbench dependencies |
